# WMSU Website Redesign - HCI Project

A redesigned prototype of the Western Mindanao State University (WMSU) website, created as a group project for Human-Computer Interaction (HCI). It addresses the usability issues found in our evaluation of the current site (wmsu.edu.ph), including inconsistent visual design, broken scaling, ambiguous navigation, dead-end portal pages, and missing interaction feedback.

This is a prototype. All data, logins, and portals are mock content and are not connected to any real university systems.

## Goals

- Provide clear, consistent navigation on every page, including portal pages
- Use a balanced color palette and a unified visual style
- Support responsive layouts from phones to desktops
- Add a dedicated Alumni section
- Follow Don Norman's design principles and basic accessibility standards

## Tech Stack

- Next.js (React)
- Tailwind CSS
- Hosted on Vercel

## Getting Started

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Project Structure

